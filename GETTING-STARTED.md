# Getting started with Bari Plux Tool

BPT for Windows brings PUBG Mobile and emulator settings, performance tools, file management and backups into one application.

## Before you install

- Use a Windows 10 or Windows 11 PC on a build supported by the current installer and its required runtimes. Check the official product page for current compatibility and download options.
- Have an internet connection for sign-in, updates and online features.
- Install the emulator you intend to use. Available tools differ between emulator profiles, devices and plans.

BPT Android is **Coming Soon**. This guide covers the Windows application.

## 1. Get the installer

Open the [official BPT product page](https://bariplux.com/tool) and follow its current download instructions. This GitHub repository contains public documentation; application installers are distributed through the official product channels.

## 2. Install and sign in

1. Run the installer and follow its instructions.
2. The installer checks required runtime components and installs missing prerequisites automatically. Allow that step to finish; follow any restart or error instructions it displays.
3. Launch Bari Plux Tool.
4. Complete sign-in in your browser and return to the application.

If installation or launch fails, use the [support guide](./SUPPORT.md).

## 3. Connect your setup

1. Open Settings and select the emulator profile you use.
2. Launch the emulator and check its connection status in BPT.
3. If detection fails, use the application's connection diagnostics or contact support with the emulator name and version.

## 4. Make your first change

1. Open the feature you need, such as FPS & Graphics or Custom View.
2. Read the available choices and any compatibility notes.
3. Where a backup option is offered, create a backup before applying changes.
4. Apply a supported setting, then check the result in your game or emulator. Use the corresponding restore option if needed.

FPS presets are configuration targets; achievable frame rates depend on game support, emulator settings and hardware.

## Keep up to date

Use the application's update check or the official product page for the current release. See the [changelog](./CHANGELOG.md) for the confirmed milestones documented here and the [roadmap](./ROADMAP.md) for future direction.
