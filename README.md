# Bari Plux Tool

**Created by Snow Breaker under the Bari Plux brand.**

BPT began as a personal tool for PUBG Mobile graphics settings and GameLoop keymapping. Community feedback helped it grow into a broader desktop application.

## Windows · BPT 3

- Graphics and FPS settings, Custom View and control profiles.
- Optimization, Game Mode and an in-game performance overlay.
- Emulator utilities, Installed Files, file management and backup / restore.
- Accounts, cloud backup, community features and updates.
- 27 languages, including right-to-left interfaces.

Availability varies by emulator, hardware and plan. Frame-rate settings depend on game and device support.

## Android · In development

Planned around gaming tools, device and network insight, accessible file management, backups and shared account features. The goal is a connected PC and mobile experience, including planned remote PC / GameLoop management. Feature support depends on device capabilities and permissions. No release date has been announced.
