# Support & feedback

## Report a bug

If BPT opens, use **Report Bug** in the application. Select a category, describe the issue and optionally attach up to **three screenshots** and a contact email.

Include:

- BPT version and Windows version.
- Emulator name and version, if the issue involves an emulator.
- Steps that reproduce the problem.
- What you expected and what actually happened.
- The exact visible error message, if there is one.

Review screenshots before sending them and remove unrelated personal or account information.

## Can't install, launch or sign in?

Email **[Support@BariPlux.com](mailto:Support@BariPlux.com)** with a short description, your Windows version, BPT version if known, and the error shown. If the issue occurred during installation, mention which step failed.

## Suggest a feature

Use the application's Report Bug form and choose the suggestion category, or share your idea in the community. Describe the task you want to accomplish, how you handle it today and how the change would help.
